# СКОЛ

**СКОЛ** — локальное настольное приложение для управления строительными работами: заявки и клиенты, объекты, сметы, производство, финансы и коммерческие предложения.

Приложение работает локально на Windows 10/11. Основная база данных хранится на компьютере; перед обновлением и восстановлением создавай резервную копию.

## Запуск из исходников
Требуются Node.js LTS и Git for Windows.

```powershell
npm install
npm start
```

## Проверки и сборка
```powershell
npm test
npm run dist:win
```

Установщик x64 называется `SKOL-Setup-<версия>.exe`.

## Сохранность данных
При переименовании продукта сохранена прежняя внутренняя идентичность Windows-приложения, а запуск проверяет старые каталоги пользовательских данных. Имя файла базы `struktura-crm.sqlite` и внутренние ключи локального хранения намеренно не переименованы: это помогает не потерять существующие данные. Не удаляй старую папку пользовательских данных до проверки запуска СКОЛ и содержимого базы.

## Безопасность
Не добавляй в Git секреты `.env`, локальные базы данных и логи.

## ИИ и поиск в СКОЛ

В приложении используется AnyModel через OpenAI-совместимый endpoint `https://anymodel.org/v1/chat/completions`. По умолчанию выбран роутер моделей `am/free`; идентификатор модели можно изменить в Настройках → ИИ.

### Первичная настройка после установки

1. Открой Настройки → Подключение ИИ.
2. Вставь собственный API-ключ AnyModel и укажи модель (по умолчанию `am/free`).
3. Нажми «Сохранить настройки ИИ».
4. Нажми «Проверить соединение».
5. После успешной проверки используй поиск компаний/заказов и помощника.

Ключ шифруется через Electron `safeStorage` и хранится в профиле пользователя Windows. Ключ не включается в исходный код, GitHub или установщик. Если ключ недоступен, обычные локальные функции CRM продолжают работать.

### Что делает ИИ

- формирует поисковые запросы для заданного направления и региона;
- ранжирует найденные страницы и выбирает только URL, которые реально вернули поисковые системы;
- помогает анализировать описание инженерного объекта: выделяет известные факты, недостающие параметры, вопросы и риски;
- отвечает на вопросы пользователя; по отдельному переключателю может получить агрегированную сводку CRM без имён и контактов.

Расчёт смет, себестоимости, сроков и производительности остаётся детерминированным. ИИ не записывает свои предположения в расчётные поля и не выполняет финансовые действия.

### Ограничения поиска

Автоматический поиск использует публичные HTML-выдачи DuckDuckGo и Bing, без Brave API-ключа. Поисковые системы могут ограничивать автоматические запросы, менять HTML-разметку или возвращать CAPTCHA. В таком случае доступны ручной поиск и импорт ссылок/CSV. Telegram, Avito и ЕИС не подключены здесь через отдельные официальные API: их страницы могут попасть в выдачу только если доступны публичному поисковику. Все найденные заказы и компании необходимо проверить на первоисточнике.

### Конфиденциальность

При использовании ИИ выбранная модель получает текст вопроса, описание объекта или переданную ей поисковую выдачу. При включённом контексте CRM передаются только агрегированные количества записей. Не отправляй персональные данные клиентов, пароли, PIN-коды и конфиденциальные документы, если не оценил условия обработки данных у AnyModel и нижестоящего поставщика модели.
