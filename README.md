# Struktura CRM

Исходный код настольного приложения Struktura CRM.

## Требования
- Windows 10/11
- Node.js LTS
- Git for Windows

## Установка
```powershell
npm install
npm run
```
Команда `npm run` покажет доступные сценарии запуска и тестирования из `package.json`.

## Безопасность
Не добавляйте в Git секреты `.env`, локальные базы данных и логи.
