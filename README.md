# Struktura CRM

Struktura CRM — настольное приложение для Windows на Electron 35, а не сайт. Данные хранятся локально на компьютере пользователя.

## Модули
- Клиенты и заявки.
- Объекты и договоры.
- Финансы: платежи, возвраты, расходы и дополнительные доходы.
- Производство и ПИ: планы, отчёты смен, прогнозы и PDF-отчёты.
- Сметы и коммерческие предложения с экспортом в PDF.
- Поиск заказчиков и заказов, импорт CSV и работа с публичными сайтами.
- Задачи, напоминания, настройки PIN и резервное копирование.

## Требования
- Windows 10/11
- Node.js 22 для разработки
- Git for Windows

## Запуск и проверки
```powershell
npm install
npm start
npm test
npm run dist:win
```
`npm run dist:win` собирает установщик Windows. Не запускайте её для обычной проверки правок: CI собирает установщик только по тегу `v*` или вручную.

## Локальная база и резервная копия
База SQLite называется `struktura-crm.sqlite` и хранится в каталоге данных пользователя Electron (`app.getPath('userData')`, обычно внутри `%APPDATA%`). Точный путь можно открыть в приложении через «Открыть папку данных».

Для резервной копии используйте встроенную команду «Создать резервную копию». Для ручного копирования полностью закройте CRM и скопируйте файл базы и связанные SQLite-файлы, если они существуют. Не копируйте активную базу при работающем приложении.

## Безопасность
Не добавляйте в Git секреты `.env`, локальные базы данных и логи. Не храните ключи API в исходниках. Не публикуйте резервные копии с клиентскими контактами и финансовыми данными.
