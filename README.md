# СКОЛ

**СКОЛ** — локальное настольное приложение для управления строительными работами: заявки и клиенты, объекты, сметы, производство, финансы и коммерческие предложения.

Приложение работает локально на Windows 10/11. Основная база данных хранится на компьютере; перед обновлением и восстановлением создавай резервную копию.

## Запуск из исходников
Требуются Node.js LTS и Git for Windows.

```powershell
npm install
npm start
```

## Проверки и сборка
```powershell
npm test
npm run dist:win
```

Установщик x64 называется `SKOL-Setup-<версия>.exe`.

## Сохранность данных
При переименовании продукта сохранена прежняя внутренняя идентичность Windows-приложения, а запуск проверяет старые каталоги пользовательских данных. Имя файла базы `struktura-crm.sqlite` и внутренние ключи локального хранения намеренно не переименованы: это помогает не потерять существующие данные. Не удаляй старую папку пользовательских данных до проверки запуска СКОЛ и содержимого базы.

## Безопасность
Не добавляй в Git секреты `.env`, локальные базы данных и логи.
