# GRUZLI CRM

Исходный код локального настольного приложения **GRUZLI CRM** для Windows: клиенты, заявки, объекты, производство, сметы, финансы и отчёты.

## Требования
- Windows 10/11
- Node.js LTS
- Git for Windows

## Установка и запуск
Откройте PowerShell в каталоге проекта и выполните:

```powershell
npm install
npm test
npm start
```

Чтобы собрать установщик Windows:

```powershell
npm run dist:win
```

Сборка установщика требует корректно установленных зависимостей Electron и доступного окружения Windows.

## Текущие ограничения
- Данные хранятся локально в SQLite на компьютере пользователя.
- Уведомления приложения не работают, когда программа полностью закрыта.
- Экран тарифов — демонстрация будущих возможностей; наличие экрана не означает, что оплата или облачная лицензия подключены.
- После переименования бренда часть внутренних технических идентификаторов намеренно сохраняет историческое имя для совместимости с существующими данными и установкой. Не меняйте `appId` без отдельного плана миграции.

## Безопасность
Не добавляйте в репозиторий API-ключи, пароли, реальные персональные данные клиентов или резервные копии рабочей базы.
