# Struktura CRM v1.14.2 — восстановление финансового раздела

## Изменения
- Возвращён раздел дополнительных поступлений: добавление и редактирование записей, дата, сумма, источник, комментарий и категория управленческого учёта.
- Восстановлена цепочка интерфейс → preload IPC → main process → SQLite.
- Таблица `income_records` создаётся через `CREATE TABLE IF NOT EXISTS`; существующая таблица и её записи не удаляются.
- Дополнительные поступления включены в общую финансовую сводку и денежный остаток.
- Поступления по объектам остаются отдельными от дополнительных доходов; доходы, привязанные к объекту, не должны повторно заноситься в дополнительный список.
- Добавлены регрессионные проверки связи интерфейса, IPC, схемы и расчётов.

## Проверки
- GitHub Actions: 183 теста пройдены, 0 ошибок.
- Автоматическая проверка синтаксиса основных Electron/renderer-файлов включена в набор тестов.
- Сборка Windows installer запускается отдельно после прохождения тестов; до появления успешного build job и артефакта EXE установщик не считается готовым.
- Запуск установленного приложения на пользовательском Windows 11 компьютере ещё требует отдельной проверки.

## Учётная оговорка
Метка «Внутренний учёт» служит для управленческой аналитики и не определяет налоговый статус поступления. Не заносить один и тот же платёж одновременно в платежи объекта и в дополнительные поступления.
