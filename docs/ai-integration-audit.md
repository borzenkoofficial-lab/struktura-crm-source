# Аудит и план внедрения ИИ в СКОЛ CRM

## Что изменено в AI-интеграции

- AnyModel подключается из главного процесса Electron через официальный OpenAI-совместимый адрес `https://anymodel.org/v1`.
- Ключ хранится отдельно от SQLite в зашифрованном файле профиля пользователя через Electron `safeStorage`. В GitHub, JS renderer и диагностические журналы ключ не попадает.
- `am/free` используется как настраиваемая чат-модель по умолчанию.
- `xai/grok-4.7` используется как настраиваемая поисковая модель с инструментом `web_search` через Responses API.
- Оба Brave-поисковых контура заменены на веб-исследование с ИИ: поиск компаний и поиск коммерческих заказов.
- Для автоматического импорта требуются проверяемые URL из web-search citations. Ответ без источников или с неверным JSON не создаёт карточки.
- Сохраняются локальные дедупликация, фильтрация типов источников, проверка URL и защита статусов, которые пользователь уже изменил вручную.
- ПИ получает отдельную пользовательскую функцию анализа агрегированных показателей без передачи ФИО, телефонов и email.

## Карта существующих модулей: где нужен ИИ, а где нет

| Модуль | Текущее назначение | Решение |
|---|---|---|
| Радар компаний | Поиск кандидатов для клиентской базы | ИИ web search + подтверждённые ссылки; сбор контактов остаётся за безопасным парсером сайтов |
| Радар коммерческих заказов | Поиск тендеров, объявлений и запросов подрядчиков | ИИ web search + источники; фильтры, дедупликация и защита статусов остаются кодом |
| ПИ / финансовые выводы | Локальная арифметика, контроль финансовых сигналов | ИИ формирует объяснения и приоритеты по агрегированным данным; расчёты остаются детерминированными |
| Экономика заказа / смета | Выручка, себестоимость, маржа, сроки | Не заменять LLM: ошибки округления или выдуманные ставки опасны |
| Производственная модель | План/факт и выработка на основе истории смен | Нормы, фактические объёмы и прогнозные формулы остаются проверяемыми алгоритмами |
| Парсер сайтов | Название и публичные email/телефоны, robots.txt и защита от SSRF | Сохранять безопасный сбор; ИИ можно добавить позднее для классификации релевантности сайта, не для угадывания контактов |
| Чтение страницы, PDF и таблиц закупки | Извлечение текста и структурированных фактов | Следующий приоритет: ИИ-разбор условий, требований к участнику, рисков, сроков подачи и состава работ с цитатами из документов |
| Калькулятор и инженерный план | Нормализация позиций и расчёт объёмов | Следующий приоритет: помощь в разборе свободного текста/сметы и сопоставлении с прайсом; цены, количества и суммы пересчитывать только локальным кодом |
| CRM: заявки, клиенты, объекты, задачи | Хранение и маршрутизация записей | Следующий приоритет: диалоговый поиск по локальным данным и подготовка черновиков задач; никаких автоматических удалений, платежей или смены статусов без подтверждения |
| Рабочий браузер | Навигация по сайтам | Не подменять браузер генерацией; ИИ может кратко резюмировать уже открытую пользователем страницу |

## Заглушки и ограничения, выявленные аудитом

- Brave Search был жёстко зашит в `src/web-search.cjs` и оба автоматических поисковых IPC-обработчика требовали отдельный ключ Brave.
- Ручные ссылки на Яндекс остаются резервным способом, а не частью автоматического радара.
- Парсер контактов обходит только переданные публичные сайты, соблюдает robots.txt и не является поисковиком.
- Оценка коммерческого заказа в `order-pi.cjs` основана на правилах и данных источника, не является ML-моделью и не должна выдавать вероятность выигрыша за реальный прогноз.
- ПИ и производственная аналитика используют формулы и историю, а не генеративный ИИ.
- В каталоге нет полноценного AI SDK и AI backend; интеграция выполняется напрямую из Electron main process без отдельного сервера.

## Эксплуатация и ограничения

1. После установки пользователь вводит AnyModel API key в разделе Настройки. Ключ хранится локально и зашифрован средствами ОС.
2. Поиск работает только при наличии интернета, действующего ключа, доступного баланса и доступности выбранной модели/инструмента веб-поиска.
3. Модель `am/free` не считается веб-поисковиком. Для актуального поиска задан отдельный маршрут `xai/grok-4.7` с `web_search`; доступ и тариф маршрута проверяются аккаунтом AnyModel.
4. Любые выводы ИИ — рекомендации. Источник, актуальность закупки, бюджет, срок подачи и контакт должны быть проверены человеком.
5. ИИ не должен самостоятельно создавать платежи, менять статусы сделок или принимать коммерческие решения.
6. API-ключ, введённый в общий чат, следует заменить перед эксплуатацией. Его нельзя включать в исходный код, коммиты, артефакты сборки или логи.

## Следующие этапы

- AI-разбор первоисточника и приложенных PDF/таблиц: техническое задание, требования к участникам, сроки, состав работ, неясные пункты и риски; каждый вывод привязывать к странице/фрагменту.
- AI-помощник сметы: разбор произвольной таблицы, единиц измерения и формулировок с обязательным подтверждением норм и цен.
- Семантический поиск по локальной CRM и диалоговое создание черновиков задач/заметок.
- AI-классификация публичных сайтов и качества лида без генерации неподтверждённых контактов.
- Регулярные тесты с фиктивным API-ответом, отдельно от ручной проверки реального AnyModel тарифа и Windows installer.
