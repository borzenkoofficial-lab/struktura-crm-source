# Выпуск офлайн-лицензий СКОЛ CRM

## Что входит

- `src/license-public-key.pem` — открытый ключ проверки, включается в Windows-приложение.
- Закрытый ключ подписи — отдельный файл владельца продукта; в репозитории его нет.
- `tools/license-generator.cjs` — локальный генератор лицензий, работает без сети.

## Однократная настройка

1. Сохрани закрытый файл подписи в отдельную папку, например `C:\\SKOL-Keys\\skol-license-private.pem`.
2. Сделай минимум две резервные копии на зашифрованных носителях.
3. Не загружай закрытый ключ в GitHub, облачные диски общего доступа, CRM покупателя или установщик.
4. Не запускай ротацию ключей без плана выпуска новой версии CRM: старый открытый ключ не сможет проверить новые лицензии, подписанные другой парой.

## Выпуск ключа

Покупатель открывает экран активации СКОЛ и копирует Device ID. Продавец получает этот идентификатор после подтверждения оплаты.

Пример для бессрочной лицензии PRO с правом обновлений до 31 октября 2027 года:

```powershell
node tools/license-generator.cjs --edition PRO --device-id <DEVICE_ID> --private-key "C:\SKOL-Keys\skol-license-private.pem" --updates-until 2027-10-31
```

Команда выводит подписанный ключ формата `SKOL1.<payload>.<signature>`. Передай покупателю всю строку целиком.

Для бессрочного права использования не указывай `--expires-at`. Параметр `--updates-until` записывает срок права на обновления; в первой версии он отображается в сведениях лицензии, но не отключает установленную программу.

## Несколько компьютеров

Офлайн-ключ привязан к одному Device ID. Для одной покупки на нескольких компьютерах выпусти отдельный ключ для каждого устройства, используя общий `--license-id`, одинаковый `--seat-count` и разные `--seat-index`.

Пример для двух устройств:

```powershell
node tools/license-generator.cjs --edition PRO --device-id <DEVICE_ID_1> --private-key "C:\SKOL-Keys\skol-license-private.pem" --license-id SKOL-ORDER-0001 --seat-index 1 --seat-count 2
node tools/license-generator.cjs --edition PRO --device-id <DEVICE_ID_2> --private-key "C:\SKOL-Keys\skol-license-private.pem" --license-id SKOL-ORDER-0001 --seat-index 2 --seat-count 2
```

## Важные ограничения

- Программа не отправляет Device ID, ключ или сведения о покупателе в интернет.
- Из-за офлайн-режима нельзя удалённо отозвать ключ или проверить, что один и тот же номер покупки не превысил количество мест на разных компьютерах. Привязка к Device ID защищает от обычного копирования ключа на другой ПК.
- При замене компьютера продавец выпускает новый ключ на новый Device ID.
- Потеря закрытого ключа не ломает уже активированные лицензии, но не позволит выпускать новые ключи для текущего открытого ключа.
