# Архив документации ранних версий СКОЛ CRM

В этой папке сохранены исторические аудиты, рабочие журналы и дорожная карта версий 1.9.0–1.13.9.

Документы перенесены из корня репозитория без изменения содержимого. Они оставлены для истории и справки; не являются актуальной инструкцией по сборке или текущим планом разработки.

Основные актуальные документы проекта находятся в корне: `README.md` и `CHANGELOG.md`.
