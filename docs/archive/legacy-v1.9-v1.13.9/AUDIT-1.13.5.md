# Аудит STRUKTURA CRM 1.13.5

## Изменение
Добавлен сценарий восстановления резервной копии SQLite через отдельную команду в меню.

## Защитные меры в коде
- Отмена выбора файла не изменяет базу.
- Источник открывается только для чтения и проходит `PRAGMA integrity_check`.
- Проверяется наличие таблиц `clients`, `leads`, `projects`, `payments`, `expenses`, `settings`.
- Перед заменой требуется отдельное подтверждение.
- Текущая база сохраняется в отдельный файл через SQLite backup API.
- После замены переподключается объект БД и перезагружается окно.
- При ошибке выполняется попытка вернуть автоматическую копию; если и откат не сработал, путь к сохранённой копии выводится в ошибке.

## Проверки этой версии
- `npm test`: 102 теста, 102 пройдены, 0 ошибок, 0 пропусков.
- `node --check`: все `src/*.js`, `src/*.cjs` и `tests/*.cjs` прошли проверку синтаксиса.
- Windows GUI, фактическое восстановление в Electron, упаковка `.exe` и печать PDF не считаются подтверждёнными без запуска на Windows.

## Ограничения
Восстановление заменяет текущую базу данными выбранного файла. Пользователь должен проверить выбранную копию и дату до подтверждения. Автоматическая страховочная копия остаётся в папке данных приложения и может занимать дополнительное место.
