# STRUKTURA CRM 1.13.4 — отчёт проверки

## Изменения
- Реализован планировщик локальных уведомлений на базе Electron Notification.
- Триггеры: просроченные/наступившие задачи; активные объекты без свежего отчёта смены; активные объекты, у которых прошёл плановый срок завершения.
- Настройки сохраняются в локальной таблице settings. По умолчанию: 09:00–19:00 по будням, проверка каждые 15 минут, отчёт смены после двух календарных дней без записи, повтор напоминания через 24 часа.
- На главной странице добавлен адаптивный информационный блок о ПИ с мокапом; демонстрационные числа явно подписаны как пример, а не данные бизнеса.

## Проверки
- Автоматические тесты: `npm test` — **100/100 пройдены**.
- Синтаксис Node.js: полный проход `node --check` по всем JS/CJS в `src` и `tests` — пройден.
- Проверка уникальности HTML ID и соответствия renderer-ссылок: включена в `tests/ui-regressions.test.cjs`.
- Проверки интерфейса: уникальность HTML ID, renderer ID refs, настройки уведомлений и мокап ПИ покрыты тестами.
- Сканирование TODO/FIXME и старого предупреждения о неработающих уведомлениях — совпадений не найдено.
- Попытка установить зависимости `npm install --no-audit --no-fund` не завершилась в доступное время; `electron`, `electron-builder` и `better-sqlite3` остались неустановленными. Поэтому запуск Electron и сборку установщика здесь выполнить нельзя. Целостность итогового ZIP проверена через `unzip -t`.

## Ограничения
- Напоминания не работают, когда приложение полностью закрыто. Это не фоновая Windows-служба и не интеграция с Google/Outlook Calendar.
- Реальные Windows toast-уведомления, интерфейс Electron и визуальная печать PDF должны быть проверены на Windows-машине; запуск тестов Node.js этого не доказывает.
- Архив основан на доступном исходном дереве 1.13.x. Это не восстановление отсутствовавшего полного исходника 1.18.0.
