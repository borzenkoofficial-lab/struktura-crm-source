# AUDIT-1.16.8 — результаты проверки

## Исправления в ветке
- Добавлен серверный контроль чистых поступлений: возвраты не могут сделать баланс объекта отрицательным; при изменении платежа редактируемая запись исключается из расчёта.
- Добавлены IPC-обработчики удаления платежей, расходов и дополнительных доходов, подтверждение в UI и сохранён общий PIN-гейт.
- Политика объектов: удаление блокируется, пока к объекту привязаны платежи или расходы.
- Расчёт финансовых значений истории КП перенесён в main и строится по строкам КП.
- Удалена неиспользуемая `projectMetrics`; добавлены CSP для статичных PDF.
- Краулер использует закреплённый проверенный IP в Undici lookup; добавлен unit-тест lookup.
- Удалён неиспользуемый IPC `browser:saveSite`; добавлены проверки стилей и паритета IPC.
- CHANGELOG, README и workflow обновлены; исторические AUDIT/WORKLOG перемещены в `docs/history/`.

## Обязательные проверки
В CI должны пройти `npm test`, `node --check src/*.js src/*.cjs tests/*.cjs` и `python3 scripts/verify-schema.py`. До завершения workflow нельзя считать проверки пройденными.

## Ограничения
- GUI, PDF и уведомления на Windows не проверялись вручную.
- Для версий 1.16.1–1.16.7 подтверждённые подробности не сохранены.
- Автоматическая сборка установщика отключена для обычных push; остаются теги `v*` и ручной запуск.
