# STRUKTURA CRM 1.9.0 — отчёт проверки

Дата: 13 октября 2026 г.

## Исправленная ошибка

В пяти обработчиках форм (заявка, клиент, объект, платёж, расход) после `await` использовался `event.currentTarget.reset()`. `currentTarget` привязан к текущему событию и после завершения синхронной обработки может стать `null`. В результате запись могла сохраниться в базе, но интерфейс падал на попытке сбросить форму. Форма теперь сохраняется в локальную переменную до асинхронного вызова, и после ответа сбрасывается через неё.

## Изменения

- Добавлена страница «Тариф и интеграции» с витриной подписки, бессрочной лицензии и профессионального пакета.
- Реальная оплата намеренно не реализована: интерфейс не списывает деньги и не утверждает, что лицензия активирована.
- Добавлен экран будущего подключения совместимого с OpenAI API провайдера. Поля API отключены; ключи не запрашиваются, не передаются и не сохраняются.
- Добавлен сдержанный эффект полупрозрачного «жидкого стекла» для боковой навигации и адаптивная сетка тарифов.
- Валидация объекта теперь проверяет название, календарную корректность дат, порядок дат и неотрицательную сумму договора.

## Ограничения проверки

В текущей среде отсутствуют установленные `electron`, `better-sqlite3` и `playwright`. Поэтому полноценный запуск Electron, проверка операций против настоящей SQLite-базы, автоматический сценарий через UI и сборка установщика Windows здесь не выполнялись. Эти проверки нельзя считать пройденными. Для полного релизного допуска нужно установить зависимости командой `npm install`, выполнить `npm test`, запустить `npm start` и вручную проверить создание объекта, затем собрать Windows-установщик на поддерживаемой среде.
